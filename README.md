## ⚡ 核心能力與特色

### 1. 鉤子-故事-超額價值-成交 銷售框架
遵循 Jemmy 經典的長文案轉換模型：
- **第一步：狠鉤子 (Hook)**：拋棄任何廢話鋪陳，第一句直接拋出真實數字與反常識矛盾。
- **第二步：痛點與真實矛盾 (Pain & Context)**：誠實交代難處，點出客戶既想解決問題又害怕受傷的真實心理。
- **第三步：超額高密度乾貨 (Front-loaded Overdeliver Value)**：把團隊內部經過驗證的第一手 SOP、工具清單直接全盤公開，讓讀者當場獲得 Immediate Win。
- **第四步：單一行動呼籲 (Single Inbound DM CTA)**：結尾杜絕多重選項，僅引導「私訊索取完整清單/連結」。

### 2. 義式濃縮咖啡法則 (Espresso Editing)
- 寫完初稿後，大刀闊斧砍掉 30%~50% 贅字。
- 嚴禁成語、形容詞堆疊與無病呻吟，每一行都追求極致知識密度與口語化。

### 3. 一人公司高槓桿思維
- 不追求盲目的案量擴張，當案量滿載時優先透過「產品化（課程/實戰營）」擴大槓桿。
- 專注高價值深度思考，瑣碎行政全面系統化與授權。

## 🚀 如何安裝與使用

### 1. 安裝至 Antigravity / Gemini CLI
直接將本資料夾複製到您的 skills 目錄：

`ash
# Windows
cp -r jkl-jemmy %USERPROFILE%\.gemini\config\skills\jkl-jemmy

# macOS / Linux
cp -r jkl-jemmy ~/.gemini/config/skills/jkl-jemmy
`

### 2. 安裝至 Claude Code / Claude Desktop
`ash
# macOS / Linux
cp -r jkl-jemmy ~/.claude/skills/jkl-jemmy

# Windows
cp -r jkl-jemmy %USERPROFILE%\.claude\skills\jkl-jemmy
`

### 3. 在對話中呼叫
安裝完成後，即可在 AI 對話中透過呼叫或自然語言提示：
- *「請以 JKL Jemmy 的口吻，幫我寫一篇關於【自由接案者如何擺脫低價競爭】的高轉換社群長文案。」*
- *「用 Jemmy 的商業文案框架，幫我這門【專業整理收納課】設計一則不用投廣告也能引發私訊索取的銷售貼文。」*
- *「如果我是 Jemmy，面對現在客戶諮詢排隊但時間不夠用的狀況，我該如何設計產品漏斗？」*
